## 1. How to read the map

Each domain is a table with five columns:

- **Ref** — the DTAC 2.0 criterion reference.
- **Criterion** — the question in the form's words, with the form's answer options and, where the form states one, its pass criterion.
- **Answer as if submitting** — what would actually be written in the box today.
- **Evidence** — the repo artefact and section that supports the answer. A path with no section means the whole file.
- **Status** — one of:
  - **EVIDENCED** — the artefact exists, is current, and answers the criterion.
  - **PARTIAL** — real evidence exists but does not fully satisfy the criterion; the shortfall is named.
  - **GAP** — nothing in the repo satisfies it. Named in §7 in the form's language.
  - **N/A (justified)** — the criterion does not apply, with the justification the form would need. DTAC 2.0 expects a rationale for out-of-scope claims, not a bare "N/A".

Status counts across the 44 criteria in C1–D1: **EVIDENCED 8 · PARTIAL 5 · GAP 18 · N/A (justified) 13.** Nine of the N/As are in C4, where the product has no integration surface by design.

**Routing path through the form**, since the form skips questions conditionally and a reviewer will check the path was followed: C1.1.1 *No* → skip C1.1.2 → C1.2 *Yes* → skip C1.2.1 → answer C1.2.2–C1.2.5. C2.1 → C2.2 *Yes* → C2.2.1–C2.2.5 → C2.2.5 *UK only* → skip C2.2.6 (answered anyway, see §5). C3.2 *No* → answer C3.3–C3.6. C4.1 *No* → C4.2 *No* → the form says "proceed to C4.3", which does not exist in form 2.0 (a drafting error in the form); C4.2.4 and C4.2.5 are answered with their explicit *Not Applicable* options. D1.4 *Yes* → D1.4.1 → D1.4.2 → D1.4.3 → D1.5.
(Section A and B fields are recorded but not counted; they are declarations, not criteria.)
